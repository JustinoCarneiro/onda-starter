# ADRs - decisões de arquitetura

Este diretório é a fonte de verdade para decisões arquiteturais ativas em um
projeto derivado. Nomeie arquivos como `NNNN-titulo-curto.md`.

Use o formato:

1. Contexto
2. Decisão
3. Consequências
4. Alternativas consideradas
5. Estado: proposta, aceita, substituída ou rejeitada

Uma decisão substituída permanece no histórico e aponta para o ADR que a
substituiu. Notas em `memoria-tecnica/decisoes/` podem complementar o contexto,
mas não substituem um ADR aceito.
