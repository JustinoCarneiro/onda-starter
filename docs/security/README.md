# Segurança

Antes de integrar autenticação, pagamentos, dados de clientes ou serviços
externos, crie ou atualize um threat model neste diretório. Use a classificação
em [data-classification.md](data-classification.md) para decidir coleta,
armazenamento, acesso, retenção e descarte.

Registre controles e riscos residuais junto à spec e aos ADRs afetados.
